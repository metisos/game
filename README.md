# Game Project

A pygame-based game with scoring system, player movement, shooting mechanics, and enemy AI.

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the game:
```bash
python game.py
```

## Running Tests

```bash
pytest tests/ -v --cov=.
```

## Features

- Player movement and controls
- Shooting mechanics
- Scoring system
- Enemy AI
- Game over screen
- Sound effects and graphics

## Development

This project follows a modular architecture with separate modules for:
- Game core logic
- Scoring system
- Player mechanics
- Enemy AI
- Graphics and sound
